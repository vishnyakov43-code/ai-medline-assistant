# AI Assistant for Medical Clinic (Medline)

## 📌 Описание проекта

AI-ассистент для сайта клиники, который:

- отвечает на вопросы пользователей
- помогает выбрать услугу
- оформляет запись на прием
- автоматически фиксирует заявки

👉 Демо: https://medlinefinal.tilda.ws/

---

## ⚙️ Архитектура

Система состоит из:

- Voiceflow — логика диалога
- Make — обработка webhook
- Google Sheets — хранение заявок
- Telegram — уведомления
![Architecture](screenshots/architecture.png)
---

## 🔄 Логика работы

1. Пользователь пишет сообщение
2. Ассистент определяет запрос
3. Ведет пользователя по сценарию
4. Собирает имя и телефон
5. Отправляет данные через webhook
6. Данные сохраняются и отправляются в Telegram

---

## 🧠 Реализованный функционал

- обработка запросов (услуги, цены, запись)
- сценарий записи
- интеграция с Google Sheets
- Telegram-уведомления
- fallback-логика

---

## 🚀 Результат

Создана работающая система лидогенерации с сайта.
